# P1 · 不同颜色内陆地表的接缝（D-065 iter-06）

> 制作人要求：不得仅扫描单一水色 RGB 判定合格；须逐格核验"同高度不同颜色"与"不同高度"的
> 边界素材使用。

## 一、本轮结论（三路证据）

1. **本轮发现的真实缺陷即 P2**：`Hill(elev1) ↔ Mount(elev2)` 的**1 级高差**此前"只有色板切换、
   无任何连接结构"（仅南向 2 级直落有墙）——**已在 P2 修复**（顶面暴露判定改为"邻位 elev <
   本格 elev"，Mount 侧三面下降边现在绘制右族顶面边缘件）。修复后，"不同颜色地表交界"的
   真实场景（Hill↔Mount）**均具备官方连接结构**（边件/墙/坡）。
2. **同高度不同颜色**：当前配置（`terrainPalette=0`，全图统一 color1/4）下不存在"同高度不同
   草地色板"的地块；草 G↔森林 F 的交界由件（右族流苏，浅青白 0%）承担——**合法边缘**，非水岸
   素材（左族）滥用。不同高度（Hill/Mount）由色板+边缘件表达，不再有"只变色不连接"。
3. **像素扫描**（iter-06 批，三种子；TS1b）：**内陆格水色系 0 格 / 0 像素**（纯水色与岸线浅青白
   双口径）；与 iter-04/05 一致。**全图选片清单**（延续 iter-04/05 判据）：0 违规。
