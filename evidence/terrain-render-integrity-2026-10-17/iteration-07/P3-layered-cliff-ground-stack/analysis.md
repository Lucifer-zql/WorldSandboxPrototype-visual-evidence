# P3 悬崖与下层陆地逐层堆叠——墙环扩展修复（iteration-07）

> 任务书 §五要求：多层地形一层叠一层；内陆悬崖下方必须由低层陆地承接，不得让背景水色直接穿透；
> 水脚与陆脚正确区分；不得用不透明草片遮盖替代分层结构；不得改变地形生成算法/抹平高差。

## 一、根因（数据实证 + 官方对照）

**修复前 `TerrainOverlayPlan.CollectWalls` 只处理南缘**（高格正南邻更低 → 墙格=南邻低格）。
**高地的东/西/北向高差边缘没有任何墙体/坡覆盖**：
- 高地 N/E/W 临水无覆盖边：**102 / 64 / 96**（三种子）——高程顶面直接接水/接低地，
  即制作人所述"高地边缘……直接露出水面"的实体；
- 高地 E/W 侧临低地（内陆高差）同样无覆盖——顶面边缘件（陆缘右族）直接贴低地草，
  缺少官方"台地边缘墙环"的侧壁结构。

**官方示意图裁定**（official-reference/README §1，裁剪 official-A/B/C）：
- 台地**南缘**：横向墙排（`_41.._44`，端帽语义）；
- 台地**东缘/西缘**：**横向墙片沿竖直方向堆叠**成墙列（v5 竖列语义：竖排叠片取无缝中段）；
- 台地**北缘：无墙**（顶面边缘件直接过渡）；
- 台地临水边缘：墙列**直接入水**（墙底缘被水面覆盖，水侧有浅青白水线）；
- 多级台地：每级台地均按上述墙环包裹——**不存在台地边缘裸接水**。

## 二、修复（生产代码，`TerrainOverlayPlan.cs`）

1. 新增 `CollectSideWall(x, y, e0, dir)`：高格的东西邻格高程**严格更低** ⇒ 该邻格为墙格；
   - 邻格为陆格（Grass/Forest）→ Row = `IsWater(邻格, y-1) ? 5 : 4`（与南缘同规则）；
   - 邻格为水格 → 仅当该水格**南邻亦水**（与南向情形 A 同判据，深水）时写 Row5（岩壁入水）；
     窄水沟保持自然形态（不写水格）；
2. 墙收集**跳过台阶格与坡候选格**（豁口语义，见 P2）；
3. 北缘不处理（官方裁定）；
4. 端帽/变体由既有 `AssignWallVariants` 自动适配（左右含对角续接；竖列 v5 → 无缝中段）。

**下层承接的渲染语义（逐层结构）**：
- 墙格 = 高格**正下方的低格**（南缘/东西缘同构）——陆格必有 Flat 底片（`_10` 内芯，100% 不透明）
  → 墙片透明区露出的是**该格真实低层陆地**，不是水背景；
- 深水墙格 = 水格（官方岩壁入水）——墙片透明区露出水面 = 官方观感（合法）；
- 高地顶面（Elevated 160）画在高格自身、墙（180）画在低格——层与层垂直相邻，**不存在"跳过中间层"**；
- 每格一个最终高程、渲染按高度差重建：Hill(elev1) 顶面 color1、Mount(elev2) 顶面 color3，
  Mount→Hill→低地的台阶面由 Mount 上段墙 + Hill 草台 + Hill 南缘墙表达（D-064 两级退台保持）。

## 四、官方限制与如实声明
- **水格墙（岩壁入水）**：官方示意图明确允许（台地临水处墙入水）；本项目按"深水≥2"判据保守启用，
  窄水沟不写水格（D-064 裁定保持）；
- **墙片仍是南向面素材**：东西缘以竖向堆叠表达侧壁（与官方一致），无专门侧壁素材；
- **净空影响**：墙格增加 → 植被净空（墙格+根部横带）扩大 → 台地边缘树木减少——官方台地边缘同样
  少植被，属预期结构变化（不是装饰损失 bug）；
- **未改地形生成算法**：elevation/terrain 数据零改动（本轮仅渲染计划与选片）。
