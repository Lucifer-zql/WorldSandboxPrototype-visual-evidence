# P0 逐层地表堆叠与内陆悬崖承接（iteration-08）

> 最高优先级交付。任务书 §四：Mount→Hill→低层陆地逐层完整；内陆悬崖下方必须有低层陆地；
> 不得靠整格不透明草片遮盖；不得抹平高差/删除墙体；须全图扫描 + 确定性场景真实截图。

## 一、根因（数据实证）

1. **中间层被墙整格覆盖**（本轮核心根因）：iter-07 的南缘/东西缘墙把 **Mount 南邻的 Hill 格**
   直接当作墙格——墙片整格高，**Hill 中间台面被墙完全覆盖**（制作人"中间层被省略"的实体）。
   三种子实测被覆盖的中间台面格：**143 / 231 / 156**（占 Hill 总量 8.7%–14.1%）。
2. **地形数据层无缺中间层**：全图统计 Mount 格南/东/西邻直邻低地（跳级）**0 / 0 / 0**
   （噪声平滑分类天然保证 Mount 环有 Hill 过渡）——中间层数据存在，缺陷在渲染计划。
3. **坡道下端无承接**（与 P2 联动）：坡片只画上段（半连接件），且 41 / 28 / 16 个坡的
   下端格是水/更高地——坡道无低层陆地承接。
4. **豁口残留墙缺失**：CollectWalls 因坡下段占用跳过墙格，坡被连续性过滤剔除后该格无任何
   连接结构（全图扫描 missingWall 41/15/12 个，东西向）。

## 二、修复（生产代码 `TerrainOverlayPlan.cs` / `TerrainTilemapRenderer.cs`）

1. **Mount 邻 Hill 不写墙**（P0 核心）：`CollectWalls` 南缘与 `CollectSideWall` 东西缘均加
   `e0 ≥ MountLevel && 邻格 elev == Hill ⇒ 不写`——Mount↔Hill 的 1 级高差由**顶面边缘件**
   （iter-06 elev-relative）表达，**Hill 中间台面完整露出**；Hill 自身南缘（邻更低）照常写墙。
   - 直落低地（Mount→低地）双段墙与深水收口规则不变。
2. **坡道成对 + 下端条件**（P2）：坡 = 上段 `_36/_39`（(X,Y)）+ 下段 `_45/_48`（(X,Y−1)）；
   坡候选要求南邻为低地干燥陆格；下段格不写墙（豁口两格）；下段只落坡列底部。
3. **孤立坡剔除补墙扩展**：剔除时对**上段与下段格**（若东西邻确有更高格）补墙——修复豁口残留。
4. 未修改地形生成算法（terrain/elevation 零改动）；未使用整格不透明覆盖；未删除任何墙体规则。
