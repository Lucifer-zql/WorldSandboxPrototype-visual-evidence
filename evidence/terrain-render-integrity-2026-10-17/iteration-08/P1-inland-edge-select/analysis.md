# P1 内陆边缘选片（iteration-08）

> 任务书 §五：内陆不同地形不得误用海岸波浪素材；混合边界逐方向分别满足语义；
> 不得把缺陷改判为"官方固有限制"；全图扫描不依赖固定 RGB。

## 一、修复（生产代码 `TerrainTilemapRenderer.cs` + 派生件）

**方案：混合缘逐方向分族 + 水向边带覆盖层（162 层）**
- 问题：单格单 Tile 无法同时"水向浅青白 + 陆向无白"——iter-07 的混合缘整格取左族（陆向波浪）
  或件格取中心片（水向缺白），二者不可兼得。
- 修复：
  1. **8 张水岸边带派生件**（`Art/Terrain/Derived/WaterEdgeBand/WaterEdgeBand_Mask{1,2,3,4,6,8,9,12}.png`）：
     从左族掩码片中**裁出暴露边 16px 边带**（实测薄荷/墨线最深 11–15px），其余置透明；
     确定性生成、原始 PNG 零改动（脚本见 `../official-reference/` 说明与 commit 记录）。
  2. **选族改为逐方向**：Flat/顶面新增 `waterMask/landMask` 拆分——
     - 纯水缘（waterMask>0 && landMask==0）→ 左族整片（浅青白岸线，行为不变）；
     - **混合缘（waterMask>0 && landMask>0）→ 右族（陆向无白）+ WaterEdgeOverlay(162) 层的
       水向边带**（水向浅青白）；band 缺失时回退左族（安全退化，与 iter-07 一致）；
     - 纯陆缘 → 右族；内芯/件格 → 中心片。
  3. `SortingOrders.WaterEdgeOverlay = 162`（04 R-LAYER-10c'）；场景接线 16 槽 Sprite 数组。
