# P2 三角坡路连接件（iteration-08）

> 任务书 §六：三角坡片是坡路连接件，不是地面装饰；上端接高地顶面、下端接低层陆地与应有的
> 悬崖结构；方向与高差一致；不得孤立摆放；不得因坡路删除必须的顶面/墙体/底层地表。

## 一、素材事实（本轮复核，含 Agent A 事后实测互证）
- `_36`(c0r4)/`_39`(c3r4) = 坡/台阶**上段**（三角草坡，α 50.2%/49.4%，直角缘在右/左）；
- `_45`(c0r5)/`_48`(c3r5) = **下段**（草坡+青灰断面，α 89.1%/90.9%）——**上段底行与下段顶行
  alpha 逐像素连续、反向零重叠**（Agent A PIL 实测）→ **坡道是 1 宽 × 2 高的连接件**；
- 资产映射：`Stair_Left_Upper/Right_Upper` 与 `Slope_Hill_Left/Right` 共用上段切片；
  `Stair_*_Lower` = `_45/_48`（Main.unity 接线）。
- 官方示意：坡片位于台地边缘墙排/墙列之间（豁口），无孤立三角（主 Agent 观察 + 官方裁剪）。

## 二、修复（生产代码 `TerrainOverlayPlan.cs` / `TerrainTilemapRenderer.cs`）

1. **坡道成对**：`SlopeCell` 增 `LowerY=Y−1`；渲染 `LayOverlays` 画上段 `_36/_39`（(X,Y)）+
   下段 `_45/_48`（(X,LowerY)），**下段只落坡列底部**（(X,LowerY) 若为另一坡上段则由该上段占据，
   官方多格坡列为"上段斜线连续 + 底部断面收口"）；
2. **下端条件**：坡候选要求南邻 (X,Y−1) 为**低地干燥陆格**——迭代扫描实测原实现 41/28/16 个坡的
   下端落在水/更高地上（坡道无承接），修复后 0；
3. **豁口两格**：`ReservedByOverlay` 同时跳过上段与下段格（墙不写，坡替代墙段）；
4. **孤立坡剔除补墙扩展**：剔除时上段与下段格（东西邻确有更高格者）补墙——修复豁口残留
   （P0 扫描 missingWall 41/15/12 → 0）；
5. 与台阶的互斥：台阶格优先，坡候选跳过台阶格（不变）。
