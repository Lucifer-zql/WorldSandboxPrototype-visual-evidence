## 一、观察记录（主 Agent 实际打开图片逐区域核对）

### 1. 台地边缘墙环（P3 核心，见 `official-A` / `official-B` / `official-C` 裁剪）
- **南缘**：横向墙排（`_41.._44` 族，端帽语义：左帽/中段/右帽/双帽）沿台地南缘排布，
  墙格位于**台地南邻的低格**上；墙排上方 = 台地顶面（草），下方 = 低地草。
- **东缘/西缘**：**横向墙片沿竖直方向堆叠**成墙列（同样位于台地东/西邻的低格上）——
  即官方把同一横墙素材用于东西向崖壁的侧壁表达（v5 竖列语义：竖排叠片取无缝中段）。
- **北缘**：**无墙**——台地顶面边缘件直接过渡到北侧地形（俯视不可见背面）。
- **临水**：台地边缘临水处墙列**直接入水**（墙底缘被水面覆盖，水侧有浅青白水线）——
  即官方允许墙格写在水格上（岩壁入水）。
- **多级台地**：每一级台地都按上述墙环包裹；层间由墙+草台表达，**不存在"台地边缘裸接水"**。

### 2. 坡片结构（P2 核心，见 `official-B`）
- 绿色三角坡片（`_36/_39`）**嵌在墙排端部/墙列之间**，作为"从低地爬上台地的豁口"——
  坡片位于低地格、紧邻墙格，**与其上下墙/坡连成一体的边缘结构**；
  **官方示意图中不存在"孤立摆在草地中央的三角片"**。
- **补充记录（Agent A 独立目视，2026-10-17）**：Agent A 对官方示意图的独立目视"未辨认出
  45° 三角坡片"（JPG 压缩与分辨率所限），其结论为"坡片是成对连接件（`_36`+`_45` 上下段接缝
  alpha 连续、反向零重叠）"，豁口处是否同时使用下段 `_45/_48` **【待验证】**。两方观察在
  "坡=边缘连接结构、无孤立三角"上一致；主 Agent 观察到墙排端部绿色斜坡（高分辨率裁剪），
  更细的官方摆法保留待验证——本条不改变 P2 修复依据（素材接缝实测 + 数据实证）。

### 3. 水岸与植被边界（P1 对照，见 `official-D`）
- 低地水岸：浅青白波浪线**沿所有方向的水陆边界**（环岛连续）。
- 草地↔森林（深绿植被）边界：**深色草叶流苏，无浅青白**（浅青白仅属于水岸线）。
- 水岸旁的植被：水岸白线与植被深色边**共存**（白线在外圈/水侧，植被边在内侧）——
  支持 iter-07 P1 修复方向：水岸白由地形层承担、植被深色流苏由件层按朝非本类掩码绘制。

### 4. 对象层序
- 官方 Guide 概念顺序（项目文档已记录并实现）：`BG Color → Water Foam → Flat Ground →
  Shadow / Elevated Ground → 更高层 Shadow / Elevated Ground 循环`；项目七层顺序见
  `SortingOrders.cs`（WaterBackground −100 / Foam −50 / Terrain 0 / ForestEdge 10 /
